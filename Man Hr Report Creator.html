Man-hour tracker

Type hours straight into the grid, or import your Excel sheet. Data stays in this browser.

Job No. = 7-digit job code from the project name – scope-of-work code – A (Revision), D (Creation) or C (Checking). A “?” means something is missing: the project name needs a 7-digit code, the task must be one of the scope-of-work names, or the description must be Revision, Creation or Checking. Output Product is the project name and Work Description is the scope of work. Vacation Leave, Sick Leave and Official Business/Undertime fall under TM Concerns; their grey placeholders are filled from days marked VL, SL or OB (regular hours per day), and you can overtype them.
