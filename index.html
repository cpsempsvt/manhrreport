How it works

Dates marked Dispatch (TJAS) use the dispatch hours and Japan holidays. All other dates use the normal hours and Philippines holidays. Holidays are marked as “Holiday” automatically on the Tracker and Timesheet, only where no day type is set yet. If you change or clear a day type yourself, it is left alone. The Philippine list covers the regular holidays and the special non-working days that recur every year, plus the 2026 additions (Chinese New Year, All Souls’ Day).

Actual MH is the logged time from the Tracker for this project, added up by work scope (the Tracker task name). Tracker tasks that don't match any row are totalled under "Other work not listed above". Plan MH is the estimated time from the Tracker tab (it updates by itself); efficiency and status are typed in. The Tracking column compares Actual with Plan: On track, Near plan (at or above the warning percentage) or Over plan. When tasks of a project have a Target set on the Tracker, one table is shown per Target, each counting only that Target’s hours; with no Target set you get the single table.

Saves one file with all your data, named after you. Save it into the shared folder your manager gave you (OneDrive or network drive). Submit again any time; saving over the same file replaces the old one.
